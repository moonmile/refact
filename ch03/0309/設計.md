## 0307 で確認された問題点

| # | 問題 | 箇所 |
|---|---|---|
| 1 | コメントに「AES-256-CBC」と書いてあるが実装は `EVP_aes_128_cbc()` (AES-128-CBC) | `make_qrcocde_url` |
| 2 | `sizeof(base64)` がポインタサイズ（8バイト）になる。`malloc` した領域のサイズではない | `base64_encode` 呼び出し箇所 |
| 3 | IV がすべてゼロ固定。同じ平文・同じ鍵で常に同じ暗号文になる | `make_qrcocde_url` |
| 4 | グローバル静的バッファ `qrcocde_url` と `data` を使用しており、スレッドセーフでない | `make_qrcocde_url` |
| 5 | 関数名・変数名に typo: `qrcocde_url` → `qrcode_url` | 全体 |
| 6 | `static strptime` が POSIX 標準の `strptime` を隠蔽する | `strptime` |

---

## リファクタリング方針

### 1. typo の修正
- `qrcocde_url` → `qrcode_url`（関数名・変数名・型名すべて）

### 2. AES コメントの修正
- コメントを「AES-128-CBC」に修正する
- 鍵長は 16 バイト（128 bit）のまま維持する

### 3. `sizeof` バグの修正
```c
// Before（バグ）
int base64_len = base64_encode(ciphertext, ciphertext_len, base64, sizeof(base64));
//                                                                   ↑ ポインタサイズ(8)

// After
int base64_len = base64_encode(ciphertext, ciphertext_len, base64, BASE64_BUF_LEN);
```

### 4. スレッドセーフ化（静的バッファの廃止）
- `qrcode_url` をグローバル静的バッファから、呼び出し側が渡すバッファへ変更する

```c
// Before
const char *make_qrcocde_url(int type, const char *device_id,
    const char *url, const char *encrypt_key, time_t t);

// After
int make_qrcode_url(char *buf, int buf_len,
    int type, const char *device_id,
    const char *url, const char *encrypt_key, time_t t);
// 戻り値: 成功時は書き込んだバイト数、エラー時は負値
```

### 5. `strptime` の隠蔽問題
- `static` な独自実装を `parse_datetime` などの別名に変更して POSIX との衝突を避ける

```c
// Before
static int strptime(const char *datetimeStr, const char *format, struct tm *tm);

// After
static int parse_datetime(const char *datetimeStr, struct tm *tm);
```

## 公開インターフェース（`qrcode_url.h`）

```c
#ifndef QRCODE_URL_H
#define QRCODE_URL_H

#include <stdint.h>
#include <time.h>

/* 文字列 "YYYY/MM/DD HH:MM:SS" を time_t に変換する */
time_t str_to_time_t(const char *fmt);

/* time_t を JST の struct tm に変換する */
struct tm *localtime_jst(time_t *t);

/* hex 文字列をバイト配列に変換する。戻り値は変換したバイト数 */
int hex_to_bin(const char *hex, uint8_t *bin, int bin_len);

/* バイト配列を Base64 文字列にエンコードする。戻り値は書き込んだ文字数 */
int base64_encode(const uint8_t *src, int src_len, char *dst, int dst_len);

/* URL エンコードを行う。戻り値は書き込んだ文字数 */
int url_encode(const char *src, int src_len, char *dst, int dst_len);

/* QRコードURL を生成する
 *   buf      : 結果を書き込むバッファ
 *   buf_len  : バッファのサイズ
 *   type     : QRコードのタイプ
 *   device_id: デバイスID
 *   url      : ベースURL
 *   encrypt_key: AES-128 鍵（16進数文字列、32文字）
 *   t        : タイムスタンプ
 * 戻り値: 成功時は書き込んだバイト数、エラー時は -1
 */
int make_qrcode_url(char *buf, int buf_len,
    int type, const char *device_id,
    const char *url, const char *encrypt_key,
    time_t t);

#endif /* QRCODE_URL_H */
```

## 暗号化データフロー

```
入力: type, device_id, timestamp
  │
  ▼
平文生成: "{type},{device_id},{YYYYMMDDHHMMSS}"
  │  例: "1,XXXXX-01234567,20241231235900"
  ▼
AES-128-CBC 暗号化
  │  鍵: encrypt_key (hex32文字 → 16バイト)
  │  IV: 0x00 × 16（固定）※ 将来的にはランダム化を検討
  ▼
Base64 エンコード
  ▼
URL エンコード
  ▼
出力: "{base_url}{encoded_ciphertext}"
  例: "https://simple.com/qrcode?msWBgyUw2s99TZP1vdX3j6BMbnvB57WHpfn5eIM7w"
```
